# AI Usage Disclosure

**Project:** **FNAF Help Wanted Archipelago**

## 1. AI Tools Used

The following AI tools were used during the development of this project:

- **Claude Code (Anthropic):** Primarily used for code generation, implementation assistance, debugging, and documentation.

## 2. Purpose of AI Usage

AI tools were used to support several aspects of the development process, including:

- Generating complete functions and sections of code.
- Debugging and identifying potential issues in the code.
- Explaining programming concepts and technical implementations.
- Improving and refactoring existing code.
- Writing and improving project documentation and code comments.
- Providing technical guidance when encountering development difficulties.

## 3. Extent of AI Assistance

AI assistance was used throughout different stages of development and contributed to a significant part of the project's codebase.

In particular, Claude Code was used as a development assistant to generate code, help implement features, troubleshoot problems, and assist with documentation.

ChatGPT and Gemini were also used to obtain explanations, explore solutions, and support technical decision-making.

The use of AI varied depending on the task and the difficulties encountered during development.

## 4. Review and Verification of AI-Generated Content

AI-generated code was not blindly accepted as final implementation.

Generated suggestions and code were reviewed, modified when necessary, integrated into the project, and tested to verify their behaviour and compatibility with the existing codebase.

AI-generated documentation and comments were also reviewed to ensure they accurately represented the project's implementation.

## 5. Personal Contribution and Responsibility

Although AI tools contributed significantly to the development process, they were used as assistance tools rather than as replacements for the developer.

The developer was responsible for directing the development process, selecting and integrating appropriate AI-generated solutions, reviewing and modifying the resulting code, testing the implementation, and ensuring that the final project met its objectives.

Full responsibility for the final submitted project, including its code, functionality, and documentation, remains with the developer.

**Declaration:** This disclosure is intended to provide a transparent account of the use of artificial intelligence tools during the development of this project.
